คู่มือการใช้งานสำหรับอาจารย์ผู้สอน
(Instructor Manual)

บทนำ (Introduction)
พิจารณาระบบเช็คชื่ออัจฉริยะ (Smart Check System) ซึ่งถูกออกแบบมาเพื่ออำนวยความสะดวกในการจัดการชั้นเรียน (Classroom Management) ช่วยลดข้อผิดพลาดในการบันทึกเวลาเรียน

ขั้นตอนการใช้งาน (Operating Procedures)

  1. การเข้าสู่ระบบ (Authentication)
    อาจารย์ผู้สอนเข้าสู่ระบบผ่านหน้าเว็บพอร์ทัล (Web Portal) ด้วยบัญชีผู้ใช้ที่ได้รับอนุมัติจากผู้ดูแลระบบ (Super Admin)
  2. การจัดการรายวิชา (Course Management)
    สามารถเพิ่มและแก้ไขรายวิชา รวมถึงระบุชื่อและรหัสวิชา (Course Code) ลงในฐานข้อมูลส่วนบุคคล
  3. การเปิดรับเช็คชื่อ (Session Activation)
    เมื่ออาจารย์กดปุ่มสร้างคิวอาร์โค้ด ระบบจะสร้างและแสดงผลคิวอาร์โค้ด (QR Code Generation) บนหน้าจอ เพื่อให้นักศึกษาสามารถทำการสแกน
    [พื้นที่สำหรับแทรกภาพตัวอย่าง QR Code บนหน้าจอ]
  4. การประมวลผลผลลัพธ์ (Data Export)
    นั่นคือ หลังจากสิ้นสุดการเรียนการสอน (End of Session) อาจารย์สามารถส่งออกข้อมูลเป็นไฟล์ตารางคำนวณ (Spreadsheet format) เช่น `.xlsx` หรือ `.docx` เพื่อนำไปวิเคราะห์ต่อไป

คู่มือการใช้งานสำหรับนักศึกษา
(Student Manual)

บทนำ (Introduction)
กระบวนการเช็คชื่อสำหรับนักศึกษาถูกออกแบบมาให้ลดความซับซ้อน (Complexity Reduction) โดยอาศัยเพียงกล้องสมาร์ทโฟน (Smartphone Camera) ในการยืนยันตัวตน

ขั้นตอนการใช้งาน (Operating Procedures)

  1. การลงทะเบียน (Registration)
    เนื่องจากระบบต้องการความแม่นยำ ดังนั้นนักศึกษาต้องทำการสมัครสมาชิกในครั้งแรกเพียงครั้งเดียว โดยระบุข้อมูลส่วนบุคคล (Personal Information) ให้ครบถ้วน
  2. กระบวนการสแกน (Scanning Process)
    ให้นักศึกษาเปิดแอปพลิเคชันกล้อง (Native Camera Application) ที่มาพร้อมกับระบบปฏิบัติการของโทรศัพท์มือถือ เพื่อสแกนคิวอาร์โค้ดหน้าชั้นเรียน

    ข้อควรระวังสำคัญ (Critical Caution):
    หลีกเลี่ยงการใช้เบราว์เซอร์ภายในแอปพลิเคชัน (In-App Browser) เช่น แอปพลิเคชัน LINE เนื่องจากข้อจำกัดด้านการอนุญาตสิทธิ์เข้าถึงฮาร์ดแวร์ (Hardware Permission Restrictions) ซึ่งอาจส่งผลให้กระบวนการทำงานล้มเหลว
    [พื้นที่สำหรับแทรกภาพการใช้กล้อง iPhone สแกน]
  3. การยืนยันการเข้าเรียน (Attendance Confirmation)
    เมื่อสแกนเรียบร้อย จะได้ลิงก์นำไปสู่เว็บเบราว์เซอร์หลัก (Main Web Browser) และขึ้นสถานะยืนยันการเข้าเรียนสำเร็จแบบเรียลไทม์
